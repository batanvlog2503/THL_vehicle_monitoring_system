🧠 Bản chất: cả team làm trên cùng 1 gốc (dev)

👉 dev = nhánh chung của cả team

Tất cả mọi người đều phải tách nhánh từ dev

👥 Ví dụ team 3 người
Người	Task	Branch
A	Login	feature/login
B	CV	feature/cv_core
C	UI	feature/ui
🚀 Quy trình CHUẨN cho mỗi người
🔹 Bước 1: Lấy code mới nhất
git checkout dev
git pull origin dev
🔹 Bước 2: Tạo branch riêng

Ví dụ bạn làm CV:

git checkout -b feature/cv_core

👉 Lúc này:

dev:            A --- B --- C
feature/cv:     A --- B --- C

✔ cùng gốc → merge được

🔹 Bước 3: Code + commit
git add .
git commit -m "add cv feature"
git push origin feature/cv_core
🔹 Bước 4: Tạo Pull Request

Trên GitHub:

feature/cv_core → dev

👉 Không merge vào main ❗

🔹 Bước 5: Merge
Team review
OK → merge vào dev
🔁 QUAN TRỌNG NHẤT (tránh conflict)

Trước khi code tiếp:

git checkout dev
git pull origin dev

git checkout feature/cv_core
git merge dev

👉 để cập nhật code mới từ team

❌ Sai lầm bạn đang gặp

Bạn đang:

tạo branch không từ dev
hoặc từ repo khác

👉 nên nó thành:

dev:      A --- B --- C
cv_core:  X --- Y --- Z  ❌

→ không merge được

🎯 Tóm lại 1 câu

👉 Cả team phải luôn tạo branch từ dev

🔥 Flow chuẩn dễ nhớ
dev (gốc chung)
 ├── feature/login
 ├── feature/cv_core
 └── feature/ui

→ tất cả merge về dev

💥 Nếu bạn đã lỡ làm sai

👉 cách nhanh nhất:

checkout dev
tạo lại branch mới từ dev
copy code cũ vào
commit lại

Nếu bạn muốn, mình có thể:

vẽ sơ đồ Git riêng cho team bạn
hoặc hướng dẫn setup Git chuẩn (tránh conflict 100%)
chưa hiểu lắm đầu tiên bắt đầu tạo repo đi và 3 người là a, b, c đi thì làm như nào

Ok, mình sẽ đi từ con số 0 → làm việc nhóm 3 người (A, B, C) theo cách dễ hiểu nhất 👇

🚀 1. Bắt đầu: Tạo repo

👉 Người A tạo repo trên GitHub

Ví dụ:

THL_vehicle_monitoring_system
👥 2. Mời team

A vào:

Settings → Collaborators → Add B, C
💻 3. Cả team clone về máy

A, B, C đều chạy:

git clone https://github.com/username/repo.git
cd repo
🌳 4. Tạo branch chuẩn

👉 A tạo 2 branch chính:

git checkout -b dev
git push origin dev

👉 Sau đó:

main = bản ổn định
dev = nơi team làm việc
👨‍💻 5. Mỗi người tạo branch riêng
🔹 A làm login
git checkout dev
git pull origin dev
git checkout -b feature/login
🔹 B làm CV
git checkout dev
git pull origin dev
git checkout -b feature/cv_core
🔹 C làm UI
git checkout dev
git pull origin dev
git checkout -b feature/ui
🧠 Lúc này cấu trúc là:
main
  |
dev
 ├── feature/login   (A)
 ├── feature/cv_core (B)
 └── feature/ui      (C)

👉 TẤT CẢ đều sinh từ dev → merge OK

✍️ 6. Mỗi người code + push

Ví dụ B:

git add .
git commit -m "add cv feature"
git push origin feature/cv_core
🔁 7. Tạo Pull Request

Trên GitHub:

👉 chọn:

feature/cv_core → dev

👉 bấm Create Pull Request

✅ 8. Team review + merge
A hoặc leader review
OK → Merge vào dev
🔄 9. Luôn cập nhật code mới (QUAN TRỌNG)

Trước khi code tiếp:

git checkout dev
git pull origin dev

git checkout feature/cv_core
git merge dev

👉 tránh conflict 💥

❌ Những điều KHÔNG được làm

❌ git init riêng
❌ tạo repo khác rồi push vào
❌ không pull trước khi code

🎯 Tóm lại siêu ngắn

👉 Flow chuẩn:

dev → tạo branch → code → PR → merge về dev
🔥 Ví dụ thực tế

B (bạn) chỉ cần nhớ:

git checkout dev
git pull origin dev
git checkout -b feature/cv_core

👉 là bạn đi đúng đường rồi
