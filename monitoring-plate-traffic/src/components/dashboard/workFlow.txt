```
Đọc frame từ video
      ↓
YOLO track → lấy ID, class, confidence, bbox
      ↓
Encode frame (đã vẽ bbox sẵn) → base64 JPEG
      ↓
Gửi JSON qua WebSocket: { frame, detections }
```

Dùng `model.track(..., persist=True)` thay vì `detect` để YOLO **giữ nguyên ID** xuyên suốt video — object A luôn là ID=1 dù di chuyển.

Khi hết video, gửi `{ status: 'done' }` để báo React kết thúc.

### React — `Dashboard.jsx`

**`startStream()`** — mở WebSocket, lắng nghe message:
```
Nhận message
      ↓
status === 'done'? → cập nhật trạng thái, dừng
      ↓
Decode base64 → vẽ lên <canvas>
      ↓
Cập nhật bảng detections (merge theo ID)
Logic merge bảng rất quan trọng:
javascriptconst idx = updated.findIndex((x) => x.id === d.id)
if (idx === -1) updated.push(d)   // ID mới → thêm dòng
else updated[idx] = d              // ID cũ → cập nhật confidence
```
→ Bảng **tích lũy tất cả object đã xuất hiện**, không bị mất khi object ra khỏi frame.
