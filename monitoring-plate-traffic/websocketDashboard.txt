🟤 F. Logic cập nhật bảng (RẤT QUAN TRỌNG)
setDetections((prev) => {
  const updated = [...prev]

  data.detections.forEach((d) => {
    const idx = updated.findIndex((x) => x.id === d.id)

    if (idx === -1)
      updated.push(d)
    else
      updated[idx] = d
  })

  return updated
})

👉 Đây là logic:

Nếu ID mới → thêm
Nếu đã có → update

👉 Kiến thức cần:

immutable state (React)
update state đúng cách
